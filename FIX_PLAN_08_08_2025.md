## 🟡 Non-Critical but Important Issues

### 3. Redis Manager Missing `close()` Method
**Problem**: Application shutdown fails because RedisManager lacks close() method

**Fix**:
```python
# In core/redis.py, add:
async def close(self):
    """Close Redis connection."""
    if self.client:
        await self.client.close()
        self.client = None
```

### 4. Session Management Issues
**Problem**: SQLAlchemy sessions getting into illegal state during concurrent operations

**Fix**:
```python
# In core/database.py:
async def get_db():
    async with AsyncSessionLocal() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
        finally:
            # Don't call close() if session is already closing
            if session.is_active:
                await session.close()
```
