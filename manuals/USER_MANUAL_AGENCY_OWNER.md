## Introduction

As an Agency Owner, you have complete control over your agency within the Agency Dark platform. This manual covers all features available to help you manage your models, staff, and business operations effectively.

## Getting Started

### First Login
1. Use credentials provided by platform administrator
2. Complete your agency profile
3. Set up payment information
4. Configure agency branding

### Your Dashboard
Upon login, you'll see:
- Agency statistics
- Recent activity
- Financial summary
- Model performance
- Pending tasks

## Dashboard Management

### Dashboard Overview
Your dashboard provides:
- **Active Models**: Currently active model count
- **Monthly Revenue**: Current month's earnings
- **Pending Payouts**: Upcoming model payments
- **New Messages**: Unread communications
- **Performance Metrics**: Key indicators

### Customizing Your View
1. Click view toggle (Classic/Custom)
2. In Custom view:
   - Drag widgets to reposition
   - Add/remove widgets
   - Resize components
   - Save layout

## User Management

### Accessing Users
**Navigation → Users**

### User Roles in Your Agency

#### Agency Admin
- Manages daily operations
- Cannot access financial settings
- Cannot modify owner account

#### Models
- Your talent/content creators
- Have individual profiles
- Generate revenue

#### Chatters
- Communicate on behalf of models
- Assigned to specific models
- Track conversation metrics

#### Agency Members
- Support staff
- Limited access
- View-only permissions

### Adding New Users

#### Adding a Model
1. Navigate to Model Overview
2. Click "Add New Model"
3. Enter details:
   - Email (required)
   - Stage Name
   - Full Name
   - Commission Rate
4. Assign chatters (optional)
5. Send invitation

#### Adding Staff
1. Navigate to Users
2. Click "Add User"
3. Select role:
   - Agency Admin
   - Chatter
   - Agency Member
4. Enter contact details
5. Set permissions
6. Send invitation

### Managing Existing Users

#### User Actions
- **Edit**: Modify user details
- **Deactivate**: Temporarily disable access
- **Delete**: Permanently remove (caution!)
- **Reset Password**: Send password reset
- **View Activity**: Check user logs

#### Bulk Operations
1. Select multiple users
2. Available actions:
   - Assign to model
   - Change roles
   - Export data
   - Deactivate

Click on any model to see:

- **Profile Completion**: How complete their profile is

1. Click model name

   - Pricing tiers
   - Availability

#### Content Oversight
- Review uploaded content
- Approve/reject posts
- Set content guidelines
- Monitor compliance

#### Chatter Assignment
1. Go to model profile
2. Click "Manage Chatters"
3. Assign/remove chatters
4. Set response guidelines
5. Monitor performance

  - Type

- Year-to-date totals
