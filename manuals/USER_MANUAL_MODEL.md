## Welcome

Welcome to Agency Dark! As a model, you have access to powerful tools to manage your content, track your performance, and grow your earnings. This guide will help you make the most of the platform.

## Getting Started

### First Login
1. Check your email for login credentials
2. Go to the platform URL
3. Enter your email and temporary password
4. You'll be prompted to:
   - Set a new password
   - Complete your profile
   - Upload a profile photo
   - Review platform guidelines

### Your Dashboard
After login, you'll automatically see your Model Dashboard with:
- **Earnings Overview**: Today, this week, this month
- **Subscriber Count**: Active subscribers
- **Recent Activity**: New subscribers, messages, tips
- **Performance Metrics**: Engagement rates
- **Quick Actions**: Upload content, check messages

## Your Profile

### Accessing Your Profile
You'll be automatically redirected to your profile dashboard, or click **Model Overview** in navigation.

### Profile Sections

#### Basic Information
- **Stage Name**: Your public name (can be different from real name)
- **Bio**: Tell subscribers about yourself
- **Profile Photo**: Your main image
- **Cover Photo**: Banner image
- **Location**: Can be general (e.g., "California")

#### Profile Completion
Keep your profile 100% complete for better visibility:
- ✅ Profile photo
- ✅ Bio (minimum 100 characters)
- ✅ At least 5 content pieces
- ✅ Pricing tiers set
- ✅ Verification completed

### Editing Your Profile
1. Click "Edit Profile" button
2. Update sections:
   - About Me
   - Interests
   - Services offered
   - Schedule/availability
3. Save changes
4. Preview how subscribers see it

### Verification Process
1. Click "Get Verified"
2. Submit required documents:
   - Government ID
   - Selfie with ID
   - Proof of age
3. Wait 24-48 hours
4. Receive verified badge ✓

## Content Management

### Uploading Content

#### Quick Upload
1. Click "Upload Content" on dashboard
2. Select files:
   - Photos: JPG, PNG (max 10MB)
   - Videos: MP4, MOV (max 500MB)
3. Add descriptions
4. Set visibility:
   - Public
   - Subscribers only
   - Premium tier
5. Publish or schedule

#### Bulk Upload
1. Navigate to Content → Bulk Upload
2. Drag and drop multiple files
3. Edit details in bulk:
   - Apply tags
   - Set pricing
   - Choose visibility
4. Review and publish

### Content Organization

#### Albums/Sets
1. Create themed collections
2. Group related content
3. Set album pricing
4. Offer bundle discounts

#### Tags and Categories
- Use relevant tags
- Popular tags get more visibility
- Categories help organization
- Subscribers can filter by tags

### Content Settings

#### Pricing Options
- **Free**: Build following
- **Subscription**: Monthly access
- **Pay-per-view**: Individual purchases
- **Tips**: Allow tipping on content

#### Scheduling Posts
1. Click calendar icon
2. Select date and time
3. Platform suggests optimal times
4. Schedule up to 30 days ahead

### Managing Existing Content

#### Content Library
View all your content:
- Filter by type
- Sort by performance
- Edit details
- Archive old content
- Delete if needed

#### Performance Tracking
For each piece:
- Views
- Likes
- Comments
- Earnings
- Engagement rate
