## Common Tasks - Step by Step

### Adding a New Model (Agency Owner/Admin)
```
1. Navigate to Model Overview
2. Click "Add New Model"
3. Enter email address
4. Set commission rate (e.g., 20%)
5. Assign chatters (optional)
6. Click "Send Invitation"
7. Model receives email with setup link
```

### Uploading Content (Model)
```
1. Click "Upload Content" button
2. Select files (drag & drop works)
3. Add descriptions for each
4. Choose visibility:
   - Free (everyone)
   - Subscribers only
   - Premium tier
5. Set price (if PPV)
6. Add relevant tags
7. Schedule or publish now
```

### Processing Payouts (Agency Owner)
```
1. Go to Financial → Payouts
2. Review pending payouts
3. Check minimum thresholds
4. Select models to pay
5. Choose "Process Selected"
6. Confirm amounts
7. Submit for processing
```

### Viewing Analytics (All Roles)
```
1. Navigate to Analytics
2. Select time period
3. Choose metrics:
   - Revenue
   - Users
   - Engagement
   - Performance
4. Apply filters if needed
5. Export or save view
```

## Keyboard Shortcuts

### Global Shortcuts
- `Ctrl/Cmd + K` - Quick search
- `Ctrl/Cmd + /` - Toggle help
- `Esc` - Close modals
- `?` - Show shortcuts

### Navigation
- `G then D` - Go to Dashboard
- `G then M` - Go to Models
- `G then A` - Go to Analytics
- `G then F` - Go to Financial
- `G then S` - Go to Settings

### Actions
- `N` - New (context sensitive)
- `E` - Edit selected
- `Delete` - Delete selected
- `Ctrl/Cmd + S` - Save changes

## Troubleshooting Quick Fixes

### Can't Login?
1. Check email/password
2. Clear browser cache
3. Try incognito mode
4. Reset password
5. Contact support

### Missing Features?
1. Check your role permissions
2. Verify agency is active
3. Clear cache and reload
4. Check for updates
5. Contact admin

### Slow Performance?
1. Check internet connection
2. Try different browser
3. Disable extensions
4. Clear browser data
5. Report to support

### Payment Issues?
1. Verify payment info
2. Check minimum threshold
3. Confirm payout schedule
4. Review transaction history
5. Contact finance team
